# Data

`raw/` and `processed/` are git-ignored. Each person downloads the data locally.

- `raw/cmapss/`: NASA C-MAPSS FD001 and FD003 (`train_FD00X.txt`)
- Taillard job-shop instances come from `job_shop_lib`, no download needed.
- `splits.json` (committed): engine-ID split into fit / calibration / test.
